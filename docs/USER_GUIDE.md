## 1. 🎉 歡迎使用智帳君

- 🌐 **官方網址**：[https://ledgy-be1e6.web.app](https://ledgy-be1e6.web.app)
- 💡 **特色**：0 秒開啟、支援離線記帳、跨裝置即時同步、長按桌面捷徑直接語音說話！

## 2. 🚀 四步驟新手設定精靈（初次使用 30 秒搞定）
當您首次註冊或登入時，智帳君會引導您完成 4 個貼心的新手設定：

| 步驟 | 設定項目 | 說明與技巧 |
| :--- | :--- | :--- |
| **第 1 步** | **基本資料與載具** | 填寫您的個人稱呼、手機載具條碼（如 `/AB1234+`）與最常用的預設付款方式（如現金、LINE Pay、信用卡等）。 |
| **第 2 步** | **標籤庫配置** | 預設為最直覺的 **「食、衣、住、行」**。您也可以直接在此新增或修改屬於您的專屬標籤（例如「貓咪」、「美妝」、「育兒」等）。 |
| **第 3 步** | **預算目標規劃** | 設定每月總預算（預設 NT$ 30,000），並可依個人習慣分配「食衣住行」個別額度，系統會即時計算預算分配進度條。 |
| **第 4 步** | **AI 智慧助理** | *（選填）* 若想使用更強大的 Gemini 財務分析顧問，可在此填入您的 Google Gemini API Key（附有免費領取教學連結）；若無填寫亦可正常使用全站所有語音與記帳功能！ |

## 3. 🎙️ AI 語音說話記帳技巧
點擊畫面底部的 **🎙️ 綠色麥克風** 按鈕（或長按手機桌面圖示點選「語音記帳」），直接對著手機說話即可秒速記帳！

### 💡 怎麼說最自然？（語音範例）
- **餐飲外食**：「*吃麥當勞大麥克 160 LINE Pay*」 ➔ 自動歸入 **【食】**、LINE Pay、NT$ 160。
- **交通加油**：「*去中油加 95 汽油 150 現金*」 ➔ 自動歸入 **【行】**、現金、NT$ 150。
- **服飾血拼**：「*買 Uniqlo 發熱衣 890 信用卡*」 ➔ 自動歸入 **【衣】**、信用卡、NT$ 890。
- **居家水電**：「*全聯買衛生紙 120 街口*」 ➔ 自動歸入 **【住】**、街口支付、NT$ 120。
- **家庭公帳**：「*算公帳 家樂福買食材 580*」 ➔ 自動切換記至 **家庭公帳**。

### 🧠 標籤自我學習功能（越用越聰明）
若某些罕見品項最初被判定為「未歸類」，您只需在明細上**手動點選切換一次正確標籤（例如切為「住」）**，智帳君就會**自動記住這個關鍵字**！下次再度說出相同品項時，系統就會 100% 自動精準配對。

## 4. 📷 統一發票掃描與自動對獎

### 🔹 掃描紙本發票
1. 點擊頂部或捷徑的 **📷 掃描發票**。
2. 將相機對準紙本發票上的 **左側與右側雙 QR Code**。
3. 智帳君會瞬間解析出發票號碼、開立日期、總金額以及所有購買的詳細品項，一鍵登錄至記帳清單！

### 🔹 自動對獎與中獎推播
- 系統內建台灣統一發票中獎資料庫，支援特別獎、特獎、頭獎至六獎，以及**雲端發票專屬 500 元 / 800 元 / 2000 元 / 百萬元獎項**。
- 進入「發票管理」頁面，點擊「一鍵對獎」即可自動核對所有已登錄發票。

## 6. 👥 家庭公帳與多人 AA 分帳結算

### 🔹 建立與切換群組
- 點擊左上方側邊欄，可自由切換 **「個人私帳」** 與 **「多人公帳」**。
- 支援建立複數群組（例如：「👫 甜蜜兩人世界」、「🏠 台北合租公寓」、「✈️ 日本東京自由行」）。

### 🔹 邀請家庭成員 / 朋友
- **方式 A（邀請碼）**：將 6 位數家庭邀請碼發送給成員，對方在「加入家庭」輸入即可。
- **方式 B（Email 邀請）**：直接在群組設定中填寫對方的 Email 發送邀請。

### 🔹 AA 分帳與最小債務清算
- 記帳時可自由勾選 **參與分攤人員**，並支援 **均等分攤、指定固定金額、自訂百分比**。
- 系統隨時在公帳頂部顯示「誰該給誰多少錢」，並採用演算法自動化簡轉帳次數（例如 A 代墊 300、B 代墊 200，系統直接計算出 B 轉給 A 50 元即可結清）。

## 7. 📊 預算規劃與統計圖表分析

- **預算進度條**：主畫面頂部即時顯示本月總預算消耗百分比，當支出接近或超過上限時，進度條會轉為醒目的警示紅字。
- **食衣住行分類預算**：可在「設定 ➔ 預算配置」設定食、衣、住、行個別的月額度，系統支援 **🤖 AI 依歷史支出一鍵智慧建議比例**。
- **多維度檢視模式**：
  - **總覽列表**：依日期降序排列的所有歷史流水帳。
  - **週收支視圖**：掌握本週每日花銷趨勢與波動。
  - **月收支視圖**：以月曆形式綜覽整月各天花費與大額支出。

## 8. 📲 PWA 桌面捷徑與手機 App 安裝教學

將智帳君加入手機主畫面，即可享有全螢幕、無網址列、秒開且支援離線記帳的原生 App 體驗！

### 🍏 iPhone / iPad (iOS Safari)
1. 使用 Safari 開啟 [https://ledgy-be1e6.web.app](https://ledgy-be1e6.web.app)。
2. 點擊 Safari 底部工具列中央的 **「分享」按鈕**（向上箭頭圖示）。
3. 向上滑動選單，點選 **「加入主畫面」**（加號圖示）。
4. 點擊右上角「新增」，完成後手機桌面即會出現「智帳君」App 圖示！

### 🤖 Android 手機 (Chrome)
1. 使用 Chrome 瀏覽器開啟網站。
2. 點擊畫面彈出的「加到主畫面」提示（或點選右上角三個點選單 ➔ 點選「安裝應用程式」/「加到主畫面」）。
3. 確認後即可在桌面生成 App 圖示。

### 🚀 長按桌面圖示快速捷徑 (App Shortcuts)
在手機桌面**長按智帳君圖示**，可直接選擇：
- 🎙️ **語音自然記帳**：直接進入說話記帳介面
- 📷 **掃描統一發票**：直接啟動相機掃描
- 💳 **出示手機載具**：結帳一秒亮出條碼
- ⚡ **快速手動記帳**：開啟金額品項手動輸入

## 9. ❓ 常見問題與疑難排解 (FAQ)

#### Q1：在電梯或沒有網路的地方可以使用嗎？
> **可以！** 智帳君具備完整的離線快取（Service Worker）能力。在無網路狀態下依然能秒開介面並持續本機記帳，待連上網路時系統會自動與雲端資料庫完成雙向同步。

#### Q2：更換手機或換瀏覽器，記帳資料會不見嗎？
> **不會！** 只要您使用同一組 Email 帳號登入，系統會立即自 Cloud Firestore 雲端資料庫拉取您所有的記帳明細、自訂標籤與預算設定。

#### Q3：Google Gemini API Key 需要付費嗎？如何取得？
> **完全免費！** 
> 1. 前往 [Google AI Studio](https://aistudio.google.com/)。
> 2. 點擊「Get API key」並使用 Google 帳號登入。
> 3. 建立並複製 API Key，貼入智帳君的「基本設定 ➔ AI 助理設定」即可免費享用 Gemini 財務顧問功能。
